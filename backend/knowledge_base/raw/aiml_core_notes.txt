AI/ML CORE NOTES

Strong AI/ML interview questions often probe how a candidate reasons about model selection, generalization, and tradeoffs rather than just naming algorithms.

Bias-variance tradeoff:
A simple model may underfit and fail to capture meaningful structure. A highly flexible model may overfit and memorize noise. Good candidates should explain how they would diagnose both cases using training and validation behavior, not intuition alone.

Regularization and generalization:
Regularization techniques such as L1, L2, dropout, early stopping, and data augmentation help reduce overfitting. A good answer should connect regularization choices to model behavior, dataset size, and expected deployment conditions.

Feature and representation choices:
In classical ML, feature engineering, data scaling, and handling missing values can be as important as model choice. In deep learning, representation learning may reduce manual feature work but increases compute cost and system complexity.

Model selection:
Candidates should be able to compare a baseline model against a stronger alternative and justify the tradeoff. They should explain when they would prefer a simpler, interpretable model over a more accurate but harder-to-debug system.

Experimental discipline:
- define a reproducible experiment plan
- track data versions and model versions
- avoid leakage between train and validation data
- compare models using the same evaluation protocol
- inspect failure cases before claiming improvement

Computer vision workflow design:
When building a CV pipeline, candidates should discuss detection or classification quality, robustness to real-world noise, post-processing choices, and the tradeoff between throughput and accuracy. They should consider not only model metrics but also system behavior in real deployment conditions.

High-signal interview concepts:
- bias versus variance
- regularization
- generalization
- feature quality
- model selection criteria
- reproducible experimentation
- evaluation under real constraints
